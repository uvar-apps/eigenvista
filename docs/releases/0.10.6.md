# EigenVista 0.10.6

## Electrostatic potential on electron-density surfaces

EigenVista can color a total electron-density mesh by the all-electron
molecular electrostatic potential from the supplied wavefunction. The density
isovalue controls the shape. The potential colors and legend use hartree/e.
Change the symmetric color range on the saved mesh without recalculating it.

## Vertex-colored Phong and translucent surfaces

The generic `surface-phong-vertex-color` shader shades the mesh colors with
Phong highlights. Transparent custom-shaded surfaces now blend visible
fragments in depth order at each pixel in the viewport and PNG export.
An opaque lobe fully occludes the geometry behind it.

Try the supplied `salicylic-acid-rhf.molden` example with the GUI or a connected
agent. The [Gallery](https://uvar-apps.github.io/eigenvista/gallery.html#salicylic-acid)
shows the mapped surface, and the
[tutorial](https://uvar-apps.github.io/eigenvista/tutorials-electrostatic-potential.html)
gives both workflows and the figure settings.

## Downloads

Install an Apple Silicon Mac or CachyOS Linux x86_64 preview from the
[GitHub release](https://github.com/uvar-apps/eigenvista/releases/tag/v0.10.6).
Each package includes the viewer, converter, examples, shaders, and AI connector.
The Mac ZIP is ad-hoc signed. The Linux package targets the qualified CachyOS
environment. See the [installation guide](https://uvar-apps.github.io/eigenvista/install.html).
