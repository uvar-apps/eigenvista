# EigenVista 0.5.13

EigenVista 0.5.13 is a development preview for Apple Silicon Macs, collecting the changes since 0.5.12.

- Protect unsaved work when closing the native window or quitting: Save, Discard and Cancel now apply to the current document, including cancelled or failed saves and late calculation results. [#30](https://github.com/uvar-apps/eigenvista/issues/30)
- Collapse any of the eight sidebar sections. Controls retain their state, expansion is remembered in the current profile, and running calculations keep progress and Cancel visible. [#48](https://github.com/uvar-apps/eigenvista/issues/48)
- Reduce Molden density-construction work by skipping exactly zero-occupation contributions after validating all orbitals. Virtual orbitals remain available for selection. [#33](https://github.com/uvar-apps/eigenvista/issues/33)
- Validate generated surfaces without creating a compressed native archive only to discard it. Write native numerical arrays directly from the Rust model, reducing encoding allocations while preserving the existing logical format, scientific values, source identities and resource limits. Older preview files remain readable; no migration is required. [#34](https://github.com/uvar-apps/eigenvista/issues/34), [#39](https://github.com/uvar-apps/eigenvista/issues/39)
- Correct the Molden capacity documentation: the existing independent limits are 1,024 basis functions and 512 molecular orbitals in total across all spin blocks. These limits have not increased. [#31](https://github.com/uvar-apps/eigenvista/issues/31)
- Update Vite to 7.3.8 and expand automatic native, browser, packaging and authentic-file compatibility checks. Chromium and WebKit verification now run independently. [#46](https://github.com/uvar-apps/eigenvista/issues/46), [#32](https://github.com/uvar-apps/eigenvista/issues/32), [#51](https://github.com/uvar-apps/eigenvista/issues/51), [#54](https://github.com/uvar-apps/eigenvista/issues/54)

Research adds independent references for affine/anisotropic rendering and documents native-save behavior. It does not enable automatic mesh compaction or isotropic resampling, change file profiles or scientific precision, or establish universal rendering accuracy or power-loss durability. The bounded anisotropy investigation [#43](https://github.com/uvar-apps/eigenvista/issues/43) is complete; save policy and platform qualification remain open in [#41](https://github.com/uvar-apps/eigenvista/issues/41).

A known volume-rendering bug remains: increasing preview quality can make a visible field disappear, including on isotropic grids. Draft quality works in the reproduced cases. [#55](https://github.com/uvar-apps/eigenvista/issues/55) tracks the repair; it is not fixed in this release.

The converter cannot create an initially absent output on the tested ExFAT volume because its atomic no-clobber publication requires hard links; `--force` does not bypass this limitation for a new filename. Existing-output replacement succeeded in the bounded test. Create the file on APFS and copy the completed output when needed. Save tests do not qualify crash or power-loss recovery.

This remains a development preview. Physical native shortcuts and file-dialog acceptance, clean-Mac/HiDPI installation, opaque geometry inside volumes, and Linux/Windows distributions still have separate qualification gates. Existing tester packaging is ad-hoc signed and not notarized.
