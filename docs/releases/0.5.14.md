# EigenVista 0.5.14

EigenVista 0.5.14 is a development preview for Apple Silicon Macs. It fixes the volume-rendering visibility bug documented in 0.5.13. [#55](https://github.com/uvar-apps/eigenvista/issues/55)

- Finer preview sampling no longer makes an otherwise visible volume disappear because each individual contribution is small.
- Volume visibility and representative depth now use accumulated opacity consistently. Depth is interpolated within the segment where the existing visibility cutoff is reached, with coverage for camera-inside views and opaque planes, spheres and meshes.
- Independent opacity, depth, initially empty/faint contributions and cutoff regressions now run in the normal Chromium/WebKit suite. Existing affine-grid, raycast and thin-feature expectations are preserved.

The fix preserves alpha integration, raycast behavior, filtering and empty-space skipping, scientific data, grid/cache policy, file profiles, precision and allocation limits. Existing preview documents need no migration. Mesh compaction and isotropic resampling remain disabled.

Volume rendering still integrates its whole ray before one depth test. Opaque objects inside an accepted ray can therefore leave behind-object contributions in its color; this release does not add scene-depth-clipped or order-independent compositing. The application remains an experimental development preview, with ad-hoc tester signing and no notarization. Clean-Mac/HiDPI installation, physical native interactions, Linux/Windows distributions and general scientific/rendering qualification remain separate gates. Existing native-save/ExFAT limitations are unchanged; see the user guide.
