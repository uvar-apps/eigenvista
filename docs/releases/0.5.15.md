# EigenVista 0.5.15

EigenVista 0.5.15 is a development preview for Apple Silicon Macs. It adds sidebar reordering while preserving your controls and active calculations. [#52](https://github.com/uvar-apps/eigenvista/issues/52)

- Drag a section's **Reorder** handle onto the upper or lower half of another section to place it before or after that section in the same sidebar.
- Use Up/Down/Home/End on the handle, or click/tap it for **Move up** and **Move down** buttons. Moves retain focus and announce the section's new position; Escape closes the controls and returns focus to the handle.
- Remember section order in the application profile, independently of expansion preferences and saved molecular files. Moving sections retains shader/file/error state, selected controls, calculation progress and Cancel, without changing scientific data or marking documents dirty.

Sections retain their existing left/right pane membership, including on mobile. Cross-pane moves are not supported. On macOS Safari, use Option-Tab if ordinary Tab skips buttons, or enable Keyboard Navigation; see the user guide.

The volume visibility/depth fix from 0.5.14 remains included. Volume rendering still integrates a whole ray before one depth test, so opaque objects inside an accepted ray can leave behind-object color. This release does not add scene-depth-clipped compositing, mesh compaction or isotropic resampling. File profiles, precision, scientific and allocation limits, dependencies, toolchain and icon/logo are unchanged; existing documents need no migration.

This remains an experimental development preview with ad-hoc tester signing and no notarization. Native physical interactions, clean-Mac/HiDPI installation, Linux/Windows distributions, general scientific/rendering qualification and power-loss durability remain separate gates. Existing native-save/ExFAT limitations are unchanged.
