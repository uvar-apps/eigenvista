# EigenVista 0.7.0

EigenVista 0.7.0 adds biological structure exploration to the molecular and
quantum-chemistry viewer: distinguish subunits, isolate components and inspect
protein folds with traces, tubes, ribbons and strand-arrow cartoons.
[#62–#66](https://github.com/uvar-apps/eigenvista/issues/62) ·
[PR #67](https://github.com/uvar-apps/eigenvista/pull/67)

For verification and Apple Silicon tester downloads, consult
[current status](https://github.com/uvar-apps/eigenvista/blob/main/docs/status.md#source-version-070)
and the [release page](https://github.com/uvar-apps/eigenvista/releases/tag/v0.7.0)
for actual delivery. Updating source does not update an installed older app.

- PDB, mmCIF and BinaryCIF imports retain selected atom names, chain/residue
  identities, label/author numbering, insertion codes, observed segments and
  supplied secondary assignments in optional biological metadata.
- **Document → Biological structure → Coloring** offers element, chain, entity
  and secondary-structure colors with a legend. Source identifiers distinguish
  otherwise ambiguous chain names; filtering keeps names and colors stable.
- Show/hide components and chains, isolate or focus a chain, select named residue
  ranges and combine per-chain/component styles. Keep detailed ligand/ion atoms
  alongside a protein overview without deleting source data.
- Choose **Backbone trace**, **Smooth tube**, **Ribbon** or
  **Secondary-structure cartoon**. Protein depictions retain original source
  picking and respect chain/TER boundaries, missing backbone atoms and unsupported
    sequence gaps. Isolated points remain visible as markers.

The tester ZIP bundles the guide’s biological illustrations and provenance for
offline viewing ([#69](https://github.com/uvar-apps/eigenvista/issues/69)).

Secondary structure is deposited only: this version does not run DSSP or predict
missing assignments. Unknown assignments remain gray unassigned loops;
unreliable ribbon orientation uses an explicit thin-tube fallback. Nucleic-acid
cartoons, glycans and molecular-shape surfaces are outside this release.

The implementation also separates neighboring chain colors, preserves valid
shared-position monomer variants without choosing an ambiguous backbone branch,
and retains the original atom element/index/coordinates inspection format with
biological context beside it.

Coloring, visibility, focus, residue ranges and per-chain/component styles are
session settings. The global representation remains saved with the document.
New native files containing biological metadata declare
`eigenvista-biological-structure-v1`; older readers that lack this capability
reject those files explicitly. Metadata-free native documents retain their
previous profile and remain readable. To recover identities discarded by an
older import, reopen the original PDB/mmCIF/BinaryCIF source. XYZ, cube and Molden
inputs are not assigned invented biological identities.

Molecular Lambert-plus-SSAO remains available for atomic spheres and bonds.
Protein depiction geometry has its own matte diffuse shading; quantum fields,
saved scientific meshes and custom shaders retain their existing paths.
Scientific precision and allocation limits, dependency/toolchain pins and the
icon/logo are unchanged. Whole-ray volume/opaque intersections and native-save/
ExFAT limitations remain.

This is an experimental development preview for Apple Silicon Macs with ad-hoc
tester signing and no notarization. Current release verification is local macOS
only; two local Linux machines will be added when access is provided. Native
physical interactions, clean-Mac/HiDPI installation, Linux/Windows distributions,
general scientific/rendering qualification and power-loss durability remain
separate gates. All relevant local checks must pass before pushing; hosted CI
is optional by explicit request.
