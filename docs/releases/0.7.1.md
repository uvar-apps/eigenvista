# EigenVista 0.7.1

EigenVista 0.7.1 renames the **Document** sidebar section to **Molecular data**
to describe its molecular counts, representation and biological controls more
clearly. [#70](https://github.com/uvar-apps/eigenvista/issues/70)

- Use **Molecular data → Biological structure** for chain/entity colors,
  component visibility and protein views.
- The section's controls and behavior are unchanged. Existing sidebar order,
  expansion preferences and control state use the same internal identifiers.
- Open/Save document terminology, Rust `Document` and native file profiles remain
  unchanged. This patch does not change molecular or quantum data, rendering
  algorithms, dependency/toolchain pins, limits or the icon/logo.

For verification and Apple Silicon tester download availability, consult
[current status](https://github.com/uvar-apps/eigenvista/blob/main/docs/status.md#source-version-071)
and the [release page](https://github.com/uvar-apps/eigenvista/releases/tag/v0.7.1).
Changing source versions does not update an installed app or an existing ZIP.

This remains an experimental development preview with ad-hoc signing and no
notarization. All relevant local checks must pass before pushing. Current
verification is local macOS only; the future two local Linux machines await
access. Native physical interactions, clean-Mac/HiDPI installation,
Linux/Windows distributions, general scientific/rendering qualification and
power-loss durability remain separate gates. Hosted CI is optional by explicit
request. The published 0.7.0 release and its artifacts remain unchanged.
