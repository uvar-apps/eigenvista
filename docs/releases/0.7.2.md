# EigenVista 0.7.2

EigenVista 0.7.2 adds scene background controls, transparent PNG export and two
optional softer atom-color palettes.

- **Background color** in the scene toolbar changes the background immediately;
  **Reset background color** restores `#e8edef`. This is a session display setting.
  [#73](https://github.com/uvar-apps/eigenvista/issues/73)
- The camera action, **Export image**, keeps `eigenvista-view.png` with the chosen
  opaque background. The separate image/download icon, **Export image with
  transparent background**, writes `eigenvista-view-transparent.png`. Empty areas
  are transparent, with alpha retained on antialiased edges and translucent
  foreground. Both actions use the current camera and restore the live view
  after success or encoder failure. [#74](https://github.com/uvar-apps/eigenvista/issues/74)
- **MatterViz Muted** and **MatterViz Pastel** are optional JSON files for
  **Atom colours → Colours file…**. Use `Palettes/matterviz-muted.json` or
  `Palettes/matterviz-pastel.json` in the tester package. They define elements 1–109;
  elements 110–118 retain built-in defaults. The original RGB values and upstream MIT
  notice are preserved. [Source and attribution](https://github.com/uvar-apps/eigenvista/blob/v0.7.2/palettes/README.md)
- Scientific data, saved-file profiles, the built-in atom palette, dependency/
  compiler pins and the icon/logo are unchanged. Palette/background choices
  remain session preferences and do not alter molecular documents.

For fresh local verification and Apple Silicon tester download availability,
consult [current status](https://github.com/uvar-apps/eigenvista/blob/main/docs/status.md#source-version-072)
and the [release page](https://github.com/uvar-apps/eigenvista/releases/tag/v0.7.2).
Changing source versions does not update an installed app or an existing ZIP.

This remains an experimental development preview with ad-hoc signing and no
notarization. All relevant local checks must pass before pushing; current
platform verification is local macOS only. Native image-download handling,
physical dialogs/quit, clean-Mac/HiDPI installation, the full supported OS range
and Linux/Windows distributions remain separate gates. The two future local
Linux hosts await access. Hosted CI is optional by explicit request. The
published 0.7.1 release and its artifacts remain unchanged.
