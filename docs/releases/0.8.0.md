# EigenVista 0.8.0

EigenVista 0.8.0 adds **AI-enabled molecular viewing**. Use Codex Desktop or CLI,
Claude Code, Pi, OpenCode or another local coding agent to operate the visible
desktop application with ordinary requests. Explore orbitals and density, load
atom palettes, color and focus protein chains, adjust representations, apply
surface shaders and export figures without learning the application API.

- The Mac app includes a prebuilt, signed connection helper, a session launcher,
  portable agent instructions, molecular examples and MatterViz palettes.
  Setup starts from the downloaded app; no source checkout, Rust, Node or
  separate MCP service is required.
- A copyable setup prompt lets an agent find the app, prepare its folders and
  check the connection. A Finder/Terminal launcher provides the manual option.
  It starts a separate enabled window and preserves existing windows.
- The shared controller uses the same molecular document, scientific worker and
  renderer as the GUI. Long calculations retain progress and cancellation.
  Authenticated local connections require explicit startup and selected file
  roots; ordinary application startup opens no control listener.
- The website adds an AI guide and four natural-language tutorials: frontier
  orbitals, density/X-ray/clipping, large-molecule ambient occlusion and mixed
  protein representations. The homepage links directly to them.
- The redistributable includes a top-level AI setup guide. Source packaging
  excludes private local notes while preserving the public sample session.

Start with the [AI overview](https://uvar-apps.github.io/eigenvista/ai.html),
[installed-app setup](https://uvar-apps.github.io/eigenvista/ai-install.html)
and [interaction guide](https://uvar-apps.github.io/eigenvista/ai-guide.html).
Agent/model accounts remain with your chosen agent; EigenVista has no embedded
chat console or model subscription. Agents may send supplied data to their
configured model provider, so choose the model and data access appropriately.

This remains an experimental Apple Silicon Mac preview, ad-hoc signed and not
Apple-notarized. The app targets macOS 13 or later; full supported-OS-range,
clean-Mac/Gatekeeper and Linux/Windows distribution qualification remain separate.
All relevant checks run locally before pushing. See
[current status](https://github.com/uvar-apps/eigenvista/blob/main/docs/status.md#source-version-080)
for the exact fresh verification, source identity and rebuilt artifact hashes.
Earlier releases retain their original source, captures and artifacts.
