A viewer for molecular data

EigenVista brings atomic structures, imported orbitals, density data and sampled scalar fields into one interactive scene.

EigenVista organizes familiar tools in one resizable left/right pane with four tabs: Molecule, Fields, Surfaces and Appearance. Measure geometry, compare molecular shape, or read a true field plane with contours and a numerical key. Hide the pane or enter Zen when the scene needs room. Explore the workspace.

From Molekel to EigenVista

EigenVista is a modern rewrite of Molekel, the molecular visualization application developed by Ugo Varetto from 2006 to 2010.

Molekel brought together molecular structures, quantum chemistry surfaces and programmable shaders. EigenVista carries that project forward with a new implementation and name.

The original Molekel repository preserves the source. The original Molekel website includes its documentation, tutorials and gallery.

Local by design

The desktop application reads and processes local files on your computer. Its scientific core is written in Rust; the interface uses React and Three.js/WebGL2, inside a Tauri desktop shell. Scientific field work runs in a background WebAssembly worker, keeping progress and cancellation available.

There is no calculation server or account required for local molecular-file workflows. This website provides documentation, examples and downloads; it does not upload or analyze your calculation files.

A native document can hold structure, supplied quantum data, sampled fields and generated meshes together. New documents use .eigenvista; older .molekel preview documents remain readable. Display choices such as the background, palette and AO remain session preferences. See the file reference for what is saved.

Know what a view means

  • Imported fields retain their declared meaning. Unknown cube units or scalar meaning are not guessed.
  • Protein secondary structure uses deposited annotations.
  • AO uses screen-space shading to emphasize depth and contact regions.
  • Display bonds are inferred or taken from supported declarations. They do not establish bond order, crystallographic symmetry or a complete chemical interpretation.
EigenVista 0.10.4 remains an experimental development preview. Downloads are available for Apple Silicon Macs and CachyOS-tested Linux x86_64. The Linux package uses system GTK 3 and WebKitGTK 4.1 and needs a graphical session. Other Linux distributions, native hardware GPU/Wayland operation, clean installations, Intel Mac, Windows and the full deployment-OS range remain unqualified. Read the Linux installation requirements. Preserve original calculation files and inspect import reports.

Images, examples and palettes

The molecular images were captured in EigenVista from public test inputs. The new workspace screenshots show a real HOMO plane and crambin SES; they retain their actual 0.9.0 source-preview identity, dimensions and camera metadata. Older image and video captures retain their original provenance too. The large-structure studies use PDB 1AON and PDB 4PJ1. See each RCSB entry for the deposited structure and its original scientific citation.

The quantum and shader studies use the C₇H₁₀ Molden example, originally distributed with Molekel. See the dataset notes for the source and orbital information. The 29-atom cube study uses complex-field.cube, originally elf_pic.cube in the same Molekel example collection. The small water Molden example remains available as a separate RHF/cc-pVDZ input. Water PDB/XYZ coordinates and the signed-affine cube are demonstration fixtures; the cube is a mathematical signed field, not a quantum calculation. Example sources and notices and the capture record preserve provenance and settings.

MatterViz Muted and Pastel are adaptations of Janosh Riebesell's MatterViz element colors. Original RGB values for elements 1–109 are retained; remaining elements use EigenVista defaults. The MIT notice accompanies both palettes. Download Pastel for the recommended AO workflow.

The website follows the brutalist laboratory-manual style of the related Sesmesh project.
