Choose the molecule and describe the result. Your agent handles the connection and calculations while you watch EigenVista.

Use Codex Desktop or CLI, Claude Code, Pi, OpenCode, or another local agent with terminal tools and an image viewer. Complete installed-app setup first. The agent reads the standalone instructions shipped in the app and translates your requests into supported actions.

Continue the session you set up

In the chat that completed setup, simply ask “What molecule is open, and what can we explore?” The agent should check for unsaved changes and running calculations before changing anything.

In a new chat, give the agent the nonsecret session note and ask “Reconnect to this EigenVista window, tell me what is open and leave the current view unchanged.” The note supplies the actual app, helper, input, output and connection filenames. Keep the private connection file's contents out of chat.

Ask for an outcome

These are independent examples. Replace bracketed files and names with your own; keep files inside your approved input folders. The bundled palettes and examples are already available to the session.

What you wantWhat to say
Open a molecule“Open [molecular file]. Tell me what it contains and any import warnings. Save a new copy of my current work first if needed.”
Compare orbitals“Find the HOMO and LUMO. Show both signs of the HOMO at an isovalue of 0.03, wait for the surface to finish, and show me an image.”
Inspect density“Show the supplied electron density as a volume first. Then make a surface at 0.04 electrons/bohr³ so we can look inside it.”
Load a palette and add depth“Load the bundled MatterViz Pastel palette, color the atoms by element, and turn on ambient occlusion using its automatic radius. Keep this camera angle.”
Use your own palette“Load the atom palette from [palette file] and show me the result. Keep the molecular data and this framing.”
Read a protein assembly“Show the protein as a cartoon and color it by chain. Isolate chain A and focus on it. Keep the complete molecular data.”
Explore a subset“Show residues [range] of chain [name]. Give that chain a ball-and-stick style while the other visible protein chains stay as cartoons. Focus on the visible structure.”
Return to an overview“Show all components again, clear individual chain and component style overrides, and use the global cartoon view. Give chains from the same molecular entity the same color and fit the complete assembly.”
Change the finish“Give this surface an X-ray finish so I can see the framework through it,” or “Cut a window into the density surface without changing the molecular data.”
Keep a comparison fair“Export AO off and on from the same camera, representation, palette and window size. Show me the actual images side by side.”
Save the result“Save a new molecular document, an opaque PNG and a transparent-background PNG in this session's Results folder. Use fresh filenames and show me the images.”
Follow a molecular surface“How is the molecular surface coming along? Tell me its current stage, elapsed time and how much of the meshing stage has finished.”
Stop a long calculation“Cancel only the calculation you started for my current request. Keep completed surfaces and the molecular data. Tell me when the app is ready again.”

You can ask for palette loading/reset, element/chain/entity/secondary-structure coloring, hiding and isolation, residue ranges, per-chain/component styles, focus and automatic AO radius directly. The agent handles these choices; no manual palette loading is needed.

Say what matters in the view

EigenVista 0.10.5 groups manual controls in four Tools tabs: Molecule, Fields, Surfaces and Appearance. You can watch or adjust the scene while your agent works; scientific requests do not depend on which tab is open. The current 0.10.5 package includes the same scientific workflows. See the current workspace.

Tell the agent which part of the molecule matters and what you want to compare. “Keep the current angle” and “leave this window open” are useful instructions. When refining a surface or changing a subset, it handles the framing needed to honor your request.

Opening another file can retain the previous background, AO and surface finish. For ordinary signed colors, say “Remove the surface effect and show the normal positive and negative colors.” The agent checks the current appearance rather than assuming it reset.

The view depends on data actually supplied in your input. Ask the agent to explain what supports the picture. Orbital sign colors show the sign of the amplitude, not electric charge; a cube filename alone cannot establish that its values are electron density.

Protect your work and wait for results

The agent should preserve unsaved work and wait for calculations and exports to finish before describing success. Opening a different file is not permission to discard changes. Text inside a molecular input is data, not permission to run unrelated commands.

If a chat or connection times out, the calculation may still be running. Ask the agent to check what happened before trying again. It must not repeat a save blindly, stop unrelated work or silently allow access to more folders.

Keep the data and the picture

Use new filenames: the connector refuses overwrites by default, and imported source files remain protected. Version 0.10.3 offers optional atomic replacement for exports to the tested Mac ExFAT volume. If you intend to replace a particular output, tell the agent explicitly; replacement can also replace a file created at that destination while export is running. Older packages may lack that option. Ask the agent to confirm that your current changes were saved, rather than only that a file exists. If an inspection edit is still applying, let it finish before saving again.

A native .eigenvista document keeps supported molecular data, generated surfaces and document appearance. Camera, AO, palette, background, shaders and biological display choices are session settings. Ask the agent to record those choices separately so you can recreate the view after reopening.

A PNG records the rendered appearance. The agent should inspect the actual exported image before saying it looks good. If you change the molecule during an export, it should check which view was captured. Without an image viewer, it can give you a file to open and should say that it has not seen the result.

Reconnect or finish

A new agent chat can reconnect using the existing nonsecret session note while the app stays open. If the app has closed, launch a new session with the packaged launcher. Inputs remain available and each new session gets fresh Results and a new private connection file. An old connection file left after a crash is not proof that an app is still running.

To finish, ask the agent to save a new copy of the work you need, stop only calculations it started for you, and leave the window open if you want to continue manually. Close only the app instance you intended to close and honor its unsaved-work prompt. Keep your results and session note.

Choose where your model runs

Molecular processing and the connection to EigenVista are local. Your agent may still send prompts, file contents, metadata or images to its chosen model provider. Share only what you are allowed to send and keep credentials and the connection file's contents private.

For on-device-only work, choose an agent that supports a local model/runtime and check its tools, telemetry and network settings. OpenCode documents local runtimes ↗. Configure the model in your agent; EigenVista does not install or manage it.

Scientific inspection

The inspection controls are included in both the GUI and the 0.10.5 app packages' connectors. Older 0.8.0 downloads predate them. Ask the agent to confirm that your connected application has these capabilities before starting.

Inspection improvements in 0.10.5. Gold reticles identify atoms selected by you or your agent; a normal inspection click shows a cyan ring for atoms not already selected. A field plane can update as you commit sampling changes, while an agent can request its replacement directly. For molecular surfaces, the agent can report the current phase, elapsed time and measured mesh completion, then cancel only its own calculation while retaining completed surfaces. A meshing percentage describes that stage, not the whole job or a remaining-time estimate. These improvements are included in the current packages.

  • “Choose this ligand copy, show complete residues within 4 angstroms, label the selected distance and save the figure and numbers.”
  • “Generate an SES with explicit radii, a 1.4 angstrom solvent probe and 0.25 angstrom spacing. Apply X-ray shading only to that surface and keep its cached geometry.”
  • “Make a true HOMO amplitude slice with a fixed colorbar from minus 0.06 to plus 0.06 and signed contours at 0.02 and 0.04. Show units, plot values along the selected bond, and export the tables and image.”

The agent handles selections, palettes, parameters, cancellation, file access and exports without handing those steps back as GUI chores. Follow the measurement, molecular-shape or quantitative-field lesson for an exact worked example.
