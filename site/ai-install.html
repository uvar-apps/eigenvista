Use EigenVista 0.10.5 for Mac or Linux. Its connection helper, launcher, instructions, examples and palettes are included together. Download and install EigenVista, then choose the setup method below. Check the included files when using an older or custom package.

Choose the agent you already use

Your agent needs local terminal/file access and, to inspect exported pictures, an image viewer. A cloud-only chat without access to the computer running EigenVista cannot control its local app. Keep an existing working agent installation; choose only one if you need to install one.

Check the compatible app package

Use the download for your operating system and CPU. No source checkout, compiler or separate MCP server is needed. Linux setup is below; its launcher and helper have different locations from the Mac app.

Mac package

Install the current EigenVista 0.10.5 Mac package from the official release page ↗. Follow the normal Mac installation guide. The connection tools below must be included:

Inside EigenVista.appPurpose
Contents/MacOS/eigenvista-ctlThe prebuilt connection helper used by the agent.
Contents/Resources/AI-connector/Start AI connection.commandThe packaged launcher for an enabled session.
Contents/Resources/AI-connector/SKILL.md and reference.mdStandalone instructions the agent reads directly. No skill registration is required.
Contents/Resources/AI-connector/README.mdThis portable user guide.
Contents/Resources/AI-connector/examples/ and palettes/Ready-to-use molecular examples and atom palettes.

If the helper or launcher is missing, this app package is not compatible. Your agent should explain what is missing and point you to the release page. Downloading instructions alone cannot enable an older app.

Manual setup on Mac

  1. Place the compatible EigenVista.app in Applications, or keep its actual installed location.
  2. In Finder, right-click the app and choose Show Package Contents.
  3. Open Contents → Resources → AI-connector and double-click Start AI connection.command.
  4. Keep the Terminal window open while this session runs. The app runs in the foreground there.
  5. Give your agent the nonsecret session note, or the displayed app, helper, input, output and connection paths. Never paste the connection file's contents.

If the app is in Applications, the equivalent Terminal command is:

"/Applications/EigenVista.app/Contents/Resources/AI-connector/Start AI connection.command"

The launcher starts one new enabled EigenVista window. It does not stop or restart other windows. Ordinary app startup does not open a connection.

Manual setup on Linux

First follow the Linux installation steps. Keep the complete extracted package, including bin/ and share/. Start the launcher from a terminal in your graphical Linux session. No Rust, Node.js or additional MCP server is required.

Inside the Linux packagePurpose
bin/eigenvista-ctlThe prebuilt helper your agent uses.
share/eigenvista/AI-connector/Start AI connection.shThe packaged Bash launcher.
share/eigenvista/AI-connector/SKILL.md and reference.mdStandalone agent instructions, with no registration step.
share/eigenvista/AI-connector/examples/ and palettes/Examples and palettes the connected agent can use immediately.

For a package extracted in Downloads, run the following. If you extracted it elsewhere, use that directory instead. These commands work in Fish and Bash:

cd "$HOME/Downloads/EigenVista-0.10.5-linux-x86_64-20261123T032215Z-b6a3f27"
"./share/eigenvista/AI-connector/Start AI connection.sh"

The file has its own Bash interpreter. Run it normally; do not source it into Fish. It opens one new connected EigenVista window, keeps existing windows alone, and prints a nonsecret session-note path. Keep that terminal open and give your agent the session-note path. Never paste the private connection file's contents.

To choose a workspace and approve a separate existing molecular-data folder, run this from the extracted package directory:

"./share/eigenvista/AI-connector/Start AI connection.sh" --workspace "$HOME/Documents/EigenVista" --input "$HOME/molecules"

Approve only the folders you intend to use. With no options, the persistent workspace and fresh per-session results follow the layout below. The app still needs a graphical display when driven by an agent; a plain SSH session does not supply one.

Your inputs persist; each session gets new results

With no options, the launcher uses ~/Documents/EigenVista:

  • Inputs/ is a persistent folder for molecular files you want the agent to use.
  • Sessions/session.XXXXXX/Results/ is a fresh results directory for each launch.
  • A private connection file lives in that session directory, outside Results. The launcher prints its filename and writes a nonsecret session note with the paths.
  • The bundled examples and palettes are available too. Ask the agent to use MatterViz Pastel; you do not need to load it manually.

Copy your chosen molecular files into Inputs, preserving originals. To allow another existing data folder, use the launcher's repeatable --input option or ask the agent to set up that approved folder for you. A different --workspace chooses the persistent base directory. Only approve the specific folders you want the agent to use.

On Mac: choose the workspace and another input folder 
"/Applications/EigenVista.app/Contents/Resources/AI-connector/Start AI connection.command" \
  --workspace "$HOME/Documents/EigenVista" \
  --input "$HOME/Documents/My molecules"

The extra input directory must already exist. Repeat --input for additional approved directories. Run the packaged launcher with --help for its options. If the app is elsewhere, use its actual path.

Keep the connection file private. A new session gets a fresh one; its contents must not be printed, uploaded or placed in chat. Use the session note to pass around the filenames. Output files use new names, so repeating a workflow keeps earlier results.

One prompt: let your agent install and connect

Paste this into your chosen local agent. It authorizes installation of a compatible binary package if needed, folder setup, a new enabled instance and connection checks. The agent handles the packaged launcher's commands. Only required system permissions, sign-in or a private-folder choice should need you.

Set up EigenVista so you can operate its desktop window for me.
Use the installed application and the connection tools packaged with it.

Check the connection and tell me which molecule is open, whether there are

I authorize this installation and setup. Ask me to act only when a required

agent/model account settings unchanged.

Public copies of the packaged agent instructions and connection reference are available when the agent needs to read them. These are instructions for the packaged tools, not a replacement for a compatible app.

Ask what is open

Once setup finishes, ask the agent to tell you what molecule is open, what supplied orbitals or densities are available, and whether there is unsaved work. Continue with ordinary requests in the interaction guide.
