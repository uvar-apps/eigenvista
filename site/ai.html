Find an orbital, reveal a density surface, load a palette or focus on one protein chain. Tell your agent what you want and watch the same EigenVista window respond.

EigenVista 0.10.3 groups manual controls in four Tools tabs: Molecule, Fields, Surfaces and Appearance. You can watch or adjust the scene while your agent works; scientific requests do not depend on which tab is open. The published 0.10.2 package includes the original scientific workflows; the new selection, plane-update and surface-progress behavior is in the 0.10.3 test build. See the current workspace.

Included in EigenVista 0.10.2 for Mac. The app ships its connection helper, launcher, agent instructions and examples together. Set up your agent and start exploring with ordinary prompts.

The app includes the connection tools

Explore scientific inspection in 0.10.3. Ask for geometry measurements/labels, ligand neighborhoods, SES/SAS molecular surfaces, and quantitative field probes/planes/profiles. The 0.10.2 Mac package and its connector include the core inspection workflows. The new selection, plane-update and surface-progress behavior is available in the 0.10.3 test build. Ask your agent to confirm available features when connecting to an older or custom app. A HOMO plane shows signed amplitude ψ; a total-density plane shows nonnegative electron density. Read the scientific-inspection manual →

A compatible EigenVista Mac app ships its connection helper, standalone agent instructions, launcher, examples and palettes together. You do not need a separate MCP plugin. Your agent reads those instructions and handles discovery, commands and progress checks.

Use Codex Desktop or CLI, Claude Code, Pi, OpenCode, or another agent with local terminal and file access. Codex Desktop already has terminal access; its CLI is optional. An image viewer lets the agent inspect and show actual PNG exports. There is no chat box or model account inside EigenVista; you keep using your chosen agent.

Two ways to get connected

  • Manual setup: open the packaged launcher in Finder or Terminal, then give your agent the nonsecret setup note.
  • One setup prompt: authorize your agent to find or download the compatible app, read its packaged instructions, start a session and check the connection.

The launcher keeps your input folder between sessions and creates a fresh private results folder each time. It starts one new enabled window and leaves existing app windows alone. You choose which data folders the agent may use.

Local viewer, chosen model

Molecular processing and the connection to EigenVista run locally. Your external agent may still send prompts, file contents or images to its chosen model provider. Share only data you are allowed to send and keep credentials and the private connection file's contents out of chat and logs.

For on-device-only work, choose an agent that supports a local model and check its tools, telemetry and network settings. OpenCode documents local runtimes ↗. Configure the model in the agent; EigenVista does not install or manage one.
