Get EigenVista 0.10.5

An experimental desktop preview for Apple Silicon Macs and CachyOS-tested Linux x86_64. Your local molecular-file workflows run on your computer, without a calculation server.

Published download: 0.10.5. Both packages include the four-tab Tools pane, scientific-inspection controls and AI connector described in this manual. It retains clearer action buttons, visible atom picks, automatic field-plane updates and molecular-surface progress. Version 0.10.5 also includes pending-edit Save coordination, optional replacement for ExFAT exports and the Accessible elements palette. These installation and first-run steps apply to the 0.10.5 package.

Before you download

  • Apple Silicon Mac: an M-series processor. This ZIP does not run on Intel Macs.
  • macOS 13 or later is the deployment target. The release was built and checked locally on macOS 27; the full supported OS range has not been qualified.
  • Linux x86_64: the CachyOS-tested archive uses system GTK 3 and WebKitGTK 4.1. Check its runtime and display requirements.
  • Windows and Intel Mac packages are not available.
  • The installed app needs no Rust, Node.js, development server or internet connection to work with local files.
Development preview. The Mac app is ad-hoc signed and is not Apple-notarized. Follow the macOS instructions below when opening it for the first time.

Install on your Mac

  1. Download and unzip the complete tester package.
  2. Move EigenVista.app into Applications.
  3. Double-click the app. It initially opens a mathematical hydrogen-pair example.
  4. Keep the rest of the extracted package: it contains examples, palettes, documentation, source and license notices.

If macOS asks about the developer

Only proceed when you trust the download's origin and integrity. After trying to open the app, go to System Settings → Privacy & Security → Open Anyway, then confirm Open for EigenVista. Managed Macs may prevent this exception.

Do not disable Gatekeeper globally. Stop and report malware or damaged-app warnings instead of bypassing them. Apple explains these security messages ↗.

Optionally verify the ZIP checksum

The companion checksum detects download corruption; it does not authenticate a publisher by itself. In Terminal, in the folder containing both downloaded files:

shasum -a 256 -c EigenVista-0.10.5-apple-silicon-20261123T032216Z-b6a3f27.zip.sha256

The result should end in OK. The ZIP's SHA-256 is:

Install on Linux

This x86_64 archive was built and tested on CachyOS, with glibc 2.44, GTK 3 and WebKitGTK 4.1 version 2.54.1. It uses those system libraries. It is not an AppImage, and compatibility with older glibc or another distribution has not been established.

You need a graphical Linux session with WebGL2. The native app was tested on an isolated X11 display; physical desktop/file-dialog behavior, Wayland and native hardware GPU operation still need qualification. An SSH connection alone does not provide a display. The standalone converter can run without one.

  1. Download the complete Linux archive and its checksum into the same folder.
  2. On CachyOS/Arch, install the runtime libraries through your normal signed package-manager workflow. Keep your distribution repositories consistent:
sudo pacman -S --needed webkit2gtk-4.1 gtk3 openssl

In Terminal, in the folder containing your downloads, verify and extract the archive. These commands work in Fish as well as Bash:

sha256sum -c EigenVista-0.10.5-linux-x86_64-20261123T032215Z-b6a3f27.tar.gz.sha256
tar -xzf EigenVista-0.10.5-linux-x86_64-20261123T032215Z-b6a3f27.tar.gz
cd EigenVista-0.10.5-linux-x86_64-20261123T032215Z-b6a3f27
./bin/eigenvista

The checksum result should end in OK. The Linux archive's SHA-256 is:

cce546de5b3f4b34a8701c6501be59634368dcbf36418d02b8afc0816215ae3f

Keep bin/ and share/ together. The examples are in share/eigenvista/Examples/; palettes and shader presets are beside them. No Rust compiler, Node.js, development server or source checkout is needed to run the installed app.

If the Linux app cannot start

Check that you downloaded the x86_64 package, installed GTK/WebKitGTK runtime dependencies and launched it inside a graphical session. Missing-library or GLIBC_… not found errors indicate a runtime mismatch. Do not replace system libraries with copies from another distribution. Report the distribution, package version, display type and full error with the build-information file. Other distributions need their own compatible build and testing.

Check your first session

The 0.10.5 app uses one resizable Tools pane. Find structure controls under Molecule, quantum rendering and numerical inspection under Fields, shape/meshes under Surfaces, and palettes/AO/shaders under Appearance. Move the pane left or right, resize it or hide it; Zen gives the view almost the whole window. See the workspace guide.

On Linux, use the examples inside share/eigenvista/Examples/. On Mac, use the package's top-level Examples/ folder.

  1. Use the app's Open button and choose Examples/water.pdb.
  2. Molecular data should show 3 atoms and 2 bonds. Display bonds are computed automatically.
  3. Drag to rotate, scroll to zoom, or use the toolbar's Zoom in and Zoom out buttons. Fit scene brings the molecule back into view.
  4. Choose Van der Waals for space-filling spheres, then return to Ball and stick.
  5. Save to a new .eigenvista file and reopen it with Open.

To try orbital and density rendering, open Examples/water.molden with the app’s Open button. To operate the viewer through Codex, Claude Code, Pi, OpenCode or another coding agent, follow AI connection setup; the connection tools are already included in your package.

If something does not look right

No quantum fields after opening a structure
Open a Molden file for orbitals and densities, or a cube file for a sampled scalar field. See supported formats.
A blank or distant scene
Use Fit scene. For sampled fields, inspect the field range and adjust the isovalue; a warning about unknown cube units does not remove the sampled field.
Navigation is slow
Turn off ambient occlusion, use a simpler representation or lower preview quality. A finer grid costs memory and computation; it is not always a better first view.
A graphics-context error
Reload or restart after a lost context. Retain original molecular inputs and save useful work regularly.
