User reference.

EigenVista displays molecular structures and supplied quantum-chemistry fields in an interactive 3D scene. This reference describes version 0.8.0, an experimental development preview. Use the installation guide to get the Mac app, or follow a worked tutorial with a downloadable example.

Find a workflow

  • Files, imports, conversion, and saving — choose a format, review import decisions, use the batch converter, and share a self-contained document.
  • Scene, appearance, and images — navigate, pick atoms, choose a representation, use ambient occlusion and palettes, export PNGs, or apply a surface shader.
  • Custom surface shaders — see through a density envelope, expose its interior with clipping, and tune lighting and transparency live.
  • Orbitals, densities, and sampled fields — generate signed surfaces, browse several orbitals, compare render modes, and understand resolution and caching.
  • Biological structures — color chains and secondary structure, show components, isolate a chain, select residue ranges, and use protein depictions.
  • AI-assisted viewing — connect your external coding agent, describe a molecular view, and keep exported figures and native documents.

The runtime badge says Native (Tauri) in the Mac app and WebAssembly in the browser viewer. On narrow windows, the panels rearrange and you may need to scroll.

Keyboard and sidebar controls

Use Tab to move between controls and Enter or Space to activate buttons. A sidebar heading is a button: activate it to collapse or expand that section. Collapsing a section retains its controls' settings and selections. In Safari on macOS, use Option-Tab if ordinary Tab skips buttons, or enable macOS Keyboard Navigation.

  1. To move a section, drag its Reorder handle onto the upper or lower half of another heading in the same sidebar.
  2. Alternatively, click or tap the handle and choose Move up or Move down.
  3. With keyboard focus on the handle, use Up/Down to move one place, or Home/End to move to the start/end of that sidebar. Focus stays on the handle and the new position is announced.
  4. Escape closes the move controls and returns focus to the handle.

The eight sections start expanded. Section order and expansion are remembered in the current browser or desktop profile across Open and restart, separately from molecular documents. Without profile storage, they last for the session. Field rendering stays open during calculations so progress and Cancel remain available; its previous expansion choice returns afterward. Reordering is available during a calculation.

The scene's Zoom in, Zoom out, Fit scene, and Reset view buttons provide alternatives to mouse gestures. See scene navigation.

What is saved?

Save writes the molecular document. It does not capture every view preference. The phrase Saved surfaces means meshes in the current document's memory; they reach disk only when you save the document.

Kind of stateExamplesAfter reopening or restarting
Saved molecular dataSelected atoms and biological identities, bonds, supplied basis/orbitals/density matrices or original sampled grids, provenance, saved meshes and generation settings.Retained in .eigenvista.
Saved document appearanceGlobal molecular representation, surface colors, opacity, and saved-mesh visibility.Retained in .eigenvista.
Session display settingsCamera, render mode, background, AO, atom palette, surface shading, shader/uniforms, preview quality, biological filters/styles, orbital checkboxes, and sampling cache.Not stored in the molecular file. Reapply after restarting; some settings continue across Open within a session.
Profile preferencesSidebar section order and expansion.Remembered on that browser/desktop profile when storage is available; not shared with the document.

Each mesh records the grid used to generate it, but the Grid resolution control resets in a new application session. Generated orbital/density grids are transient; their analytic inputs and saved meshes persist. Imported cube grids retain their original values. See saving and sharing and field caching.

When something looks wrong

SymptomNext step
Generate surfaces is disabledSelect an orbital, density matrix, or sampled field in Quantum fields. Wait for another active operation to finish or cancel it.
Generate selected is disabledCheck between 1 and 32 orbitals and enter a finite positive isovalue.
Raycast/volume choices are disabledSelect an available field and finish/cancel other active work. Analytic orbital/density previews do not require meshes.
No field appearsUse Fit scene, check the selected mode and field, and try a smaller positive isovalue. Read any preview error. An all-zero field has no nonzero surface.
A structure seems missingFit the scene, try Ball and stick, and check counts and biological visibility filters. Show all components clears those filters.
Atom/bond counts differ from the sourceRead Provenance: model, alternate, occupancy, unknown-element, declared-connection, and inferred-bond policies can change the selected display structure.
A calculation is slow or exceeds a boundRead phase/counts and elapsed time. Cancel, then use fewer orbitals or a lower grid resolution. Existing completed surfaces are retained on recoverable errors.
Volume changes unexpectedly with qualityUse 0.5.14 or later; earlier builds had an opacity/quality interaction. In all versions, volume intersections with opaque objects remain approximate.
A file is rejectedRead the exact error and supported profile. Export an appropriate supported file rather than removing producer, units, or validation markers.
WebGL2 is unavailable / graphics context lostCheck graphics acceleration. A lost context requires restart/reload; save if possible beforehand. Unsaved data can be lost.

See supported file formats for import options and rendering limits for guidance on sampled previews and transparency.

For a problem report, include the package filename or BUILD-INFO.json, Mac model/processor, OS version, exact error, steps, and a screenshot. Share a small input only if you have permission to publish it. Keep confidential research data out of public issues.
