04.4 / EIGENVISTA FIELD MANUAL

Read a large biological structure.

On this page

This guide follows EigenVista 0.10.3. Use the four tabs in the single Tools pane: Molecule, Fields, Surfaces and Appearance. The published 0.10.2 Mac package includes the workspace and original inspection tools; the selection, plane-update and surface-progress improvements belong to the 0.10.3 test build. Find your way around the current workspace →

Get ready

Download 1AON.cif and matterviz-pastel.json. 1AON is a deposited GroEL–GroES chaperonin complex. This file imports 58,870 selected atoms, making it a useful example of broad molecular folds and crowded contacts. Read the data source and palette notices.

Outcome: an atom-colored space-filling AO view, a chain overview, an isolated protein view, and a PNG of your chosen framing. This is a local graphics workload; allow import and scene preparation to finish before navigating.

1. Prepare the atomic view

  1. Click Open and choose 1AON.cif. Wait for the import to finish. Choose Molecule → Molecular data, check 58,870 atoms, and open Provenance in the same tab for model, alternate-location, and connection decisions.

  2. Set Representation → Van der Waals for space-filling atomic spheres.

  3. In Molecule → Molecular data → Biological structure, set Coloring → Element. This is necessary for the element palette to be visible instead of chain, entity, or secondary-structure colors.

  4. Choose Appearance → Atom colours, click Colours file…, and choose matterviz-pastel.json. Confirm that its filename replaces the built-in palette label. The lighter colors make shaded contacts easier to read.

  5. Click Fit scene. Rotate to a useful view of the complex, then leave the camera unchanged for the comparison.

Checkpoint: you see atomic spheres colored by element with the Pastel palette.

2. Compare normal lighting and ambient occlusion

  1. In the Appearance tab, expand the Appearance widget and leave Ambient occlusion off initially. Observe the contacts and central recesses. Optionally export this view before continuing.

  2. Enable Ambient occlusion. Active AO uses Lambert shading plus SSAO, without specular highlights. Keep Automatic AO radius checked and read AO radius (angstrom).

  3. Adjust AO strength while keeping camera, palette, representation, and background unchanged. Compare a moderate strength with zero, then toggle AO off and on. Zero or Off restores normal molecular rendering.

  4. For a closer experiment, uncheck Automatic AO radius. The manual slider starts from the automatic value: smaller radii emphasize nearby contacts; larger radii can emphasize broader recesses. Recheck automatic radius afterward.

Checkpoint: the shading changes while atom counts, connectivity, and element colors stay the same. The automatic radius comes from the atom-coordinate extent, so zooming does not change that radius. The visible effect can still change with the camera.

AO emphasizes depth and contact regions by shading atomic spheres and bonds; hidden and offscreen geometry affect what the screen-space method can show. Turn it off if navigation slows. The gallery provides the paired captures for comparison.

3. Switch to chains and protein cartoons

  1. Set Ambient occlusion off. Switch to Molecule → Molecular data, choose Representation → Protein cartoon, then Biological structure → Coloring → Chain. Use Fit scene to frame the complete complex.

  2. Expand Chains. Each row identifies a deposited chain instance. If needed, use Filter chain or entity to find the chain you want; the list displays at most 50 matching entries.

  3. For chain A, use Isolate, then Focus. Alternatively, Focus visible structure frames all currently visible atoms. A chain style can override a component style, and either can override the global representation.

  4. Choose Coloring → Secondary structure. Inspect deposited helices, strand arrows, and unassigned loops. Click an atom where atomic detail is visible to inspect its biological context.

  5. Use Show all components to clear isolation and visibility/range filters. Return to Coloring → Element and Representation → Van der Waals when you want the atomic AO view again.

Checkpoint: isolation hides other chains without removing them from the document. Missing backbone atoms, chain boundaries, and unsupported gaps break protein paths rather than inventing connections. Nonprotein components retain atomic representations.

4. Export the view and save the data

  1. Choose your final representation, colors, and framing. To capture the shaded atomic view, restore Element, Van der Waals, the Pastel palette, and your AO settings first.

  2. Use the viewport’s camera button, Export image, for eigenvista-view.png. Or use Export image with transparent background for eigenvista-view-transparent.png. The PNG includes current scene shading and camera framing; toolbar and status text stay out. Exports also include visible labels, measurement monitors and numeric keys. Check that your host completed the download.

  3. Click Save and choose a new filename such as 1aon-study.eigenvista. This retains the selected molecular data, biological identities, connectivity, and global representation. Keep the original mmCIF file too.

Session versus Save: AO, atom palette, background, biological coloring, chain/component style overrides, visibility, isolation, residue ranges, and focus are session settings. They are not written into .eigenvista. Camera framing is also not saved. Reload starts with AO off and the built-in atom palette; load Pastel and restore your display choices to recreate the illustration. A PNG captures the current appearance but is not a molecular document.

Image export uses the host’s download mechanism. Confirm that the actual PNG arrived and inspect it before relying on it.

If something differs

If Pastel seems ineffective, choose Coloring → Element. If an isolated chain vanishes, use Show all components, check chain/component filters, and focus again. If AO reports an enhancement error, disable and re-enable it to retry; normal molecular rendering remains available. A lost graphics context requires a reload, so Save completed work first when possible.

Continue in the biological structure reference for component styles and residue ranges, or the scene reference for palettes, backgrounds, and PNG export. Return to the learning path to explore calculated fields.
