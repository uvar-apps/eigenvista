04.1 / EIGENVISTA FIELD MANUAL

Your first molecule.

On this page

Get ready1. Open and check water2. Move and inspect3. Change the representation4. Save and reopenIf something differs
This guide follows EigenVista 0.10.1. Use the four tabs in the single Tools pane: Molecule, Fields, Surfaces and Appearance. The 0.10.1 Mac package includes this workspace and its scientific-inspection tools. Find your way around the current workspace →

Get ready

You need the installed Mac preview and water.pdb. The alternative water.xyz gives the same 3-atom, 2-bond check. These files supply geometry, with coordinates in angstroms. No quantum-chemistry program is needed.

Outcome: a water structure you can navigate and inspect, saved as a new .eigenvista document.

1. Open and check water

  1. Launch EigenVista. If the initial mathematical example is visible, click Open and choose the downloaded water.pdb. If asked about changed content, save anything you want to keep before replacing it.

  2. Choose Molecule and expand Molecular data if necessary. Check 3 atoms and 2 bonds. The importer computes display connectivity even when an input does not supply explicit connections.

  3. Open Molecule → Provenance to see import decisions. Then choose Fields → Quantum fields: it should say No quantum fields. The imported document remains unsaved until you explicitly Save.

Checkpoint: you can see one oxygen and two hydrogens. The two bonds are generated automatically from the atom positions.

2. Move and inspect

  1. Left-drag in the scene to rotate. Right-drag or Ctrl-drag to pan. Scroll to zoom, or use the viewport’s Zoom in and Zoom out buttons. On a touchscreen, one finger rotates and two fingers pinch or pan.

  2. Click an atom. The status below the scene identifies its element and index and shows coordinates in angstroms. To create an actual distance or angle, use Molecule → Selections and measurements in a matching current build; see the measurement lesson.

  3. Click Fit scene to restore the default framing and direction. You can Tab to toolbar buttons and activate them with Enter or Space.

Checkpoint: the atom and bond counts stay the same while you navigate. If the molecule leaves the view, Fit scene brings it back.

3. Change the representation

  1. Under Molecule → Molecular data → Representation, try Ball and stick, then Liquorice.

  2. Choose Van der Waals for space-filling spheres. Bond cylinders disappear in this representation; the document still contains its two bonds.

  3. Return to the representation you want to keep. A representation change marks the document as changed.

4. Save and reopen

  1. Click Save. Choose a new filename such as my-water.eigenvista in the native destination dialog and finish saving. Preserve water.pdb.

  2. Click Open and choose your new .eigenvista file. Confirm that it still has 3 atoms, 2 bonds, and the representation you saved.

  3. Use Fit scene if needed. Camera position is not saved, so reopening does not reproduce your exact viewing angle.

Checkpoint: the native document is self-contained for the imported structure and connectivity. Save does not write PDB or XYZ, and opening an input never overwrites it.

If something differs

If the initial example is still visible, use the app’s Open button and select the downloaded file again. Finder file associations and drag-and-drop loading are not implemented. If counts differ, verify the filename and read Provenance and the error message. For an apparently empty view, try Fit scene and Ball and stick.

Next, explore the hydrocarbon’s calculated orbitals to add quantum fields. For all navigation and appearance controls, see the scene reference.
