Before you start

Use the EigenVista 0.7.2 Mac preview for these lessons. Open the downloaded example files with the app’s Open button. The website supplies instructions and data; the installed app runs the local molecular workflows.

Start with the first lesson if you are new to the viewport. Then choose the kind of data you work with. Keep the original inputs and save your work to new .eigenvista files.

EigenVista is a development preview. It visualizes supplied scientific data; atom coordinates alone do not produce a wavefunction. The lessons distinguish calculated data, mathematical test fields, and illustrative rendering effects.

Your learning path

  1. Open, inspect, and save your first molecule. Use three-atom water to learn rotation, zoom, picking, representations, and native Save.

  2. Explore orbitals from a real calculation. Browse the calculated water wavefunction, preview one field without a mesh, then generate and save signed surfaces.

  3. Inspect a sampled cube field. Compare a raycast with stored triangles and learn what survives saving a skewed scalar grid.

  4. Read a large biological structure. Use MatterViz Pastel and ambient occlusion on 1AON, then switch to chain cartoons and isolate a chain.

How to use the checkpoints

Each lesson gives an expected result before the next action. Wait for the footer’s completed result when a calculation is running. A calculation’s live phase percentage is not a whole-job completion indicator. Cancel retains previously completed surfaces.

If your controls differ, check the installed version and expand the relevant sidebar heading. Use Fit scene if an object appears missing. The user reference covers the complete controls and current limits; the gallery shows real application captures.
